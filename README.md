# okane — 借入金・貸付金 かんたん管理

Googleスプレッドシート + Google Apps Script（GAS）だけで動く、超シンプルな「誰にいくら貸した／借りた」管理アプリです。

## できること

- 4種類の記録: **貸した / 返してもらった / 借りた / 返した**
- 相手ごとの残高を自動計算（返してもらう額 / 返す額）
- 貸付残高・借入残高の合計表示
- 履歴の一覧と削除
- データは「取引」シートにそのまま保存されるので、シートで直接見たり編集したりもOK

## セットアップ（5分）

1. 新しいGoogleスプレッドシートを作成
2. メニュー **拡張機能 → Apps Script** を開く
3. `コード.gs` の中身を全部消して、[`src/Code.gs`](src/Code.gs) の内容を貼り付け
4. 左の「ファイル ＋」→ **HTML** を選び、名前を `Index` にして、[`src/Index.html`](src/Index.html) の内容を貼り付け
5. 保存（💾）
6. スプレッドシートを再読み込みすると、メニューに **💰 お金管理** が出ます
7. **💰 お金管理 → アプリを開く** でサイドバーにアプリが表示されます
   - 初回は権限の承認を求められるので「許可」してください
     （「このアプリは確認されていません」と出たら「詳細」→「〇〇（安全ではないページ）に移動」）

## Netlifyで公開する（スマホ向け・おすすめ）

画面は Netlify、データは今までどおりスプレッドシートに保存されます。

### 1. GAS側（API化）
1. `コード.gs` を最新の [`src/Code.gs`](src/Code.gs) に貼り替えて保存
2. スプシを再読み込み → **💰 お金管理 → Netlify連携の設定を表示**
   → **APIトークン** が表示されるのでメモ（初回に自動発行）
3. Apps Scriptで **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**（トークンを知らない人は読み書きできません）
4. 表示された `https://script.google.com/macros/s/…/exec` の URL をメモ

> コードを直したら「デプロイを管理 → ✏️ → 新バージョン → デプロイ」で反映されます。

### 2. Netlify側
1. Netlify で **Add new site → Import an existing project** からこのリポジトリを選択
   （ビルド設定は [`netlify.toml`](netlify.toml) で自動。`web/` がそのまま公開されます）
   - もしくは [`web/`](web) フォルダを Netlify Drop にドラッグ＆ドロップでもOK
     （その場合はセキュリティヘッダー用に `netlify.toml` も一緒に入れてください）
2. 公開されたサイトを開き、**接続を設定する** に API URL とトークンを入力
3. スマホのブラウザで「ホーム画面に追加」するとアプリのように使えます

`https://（サイト）/?demo` で開くと、接続しなくてもデモデータで試せます。

### Netlify版の特長
- スマホ最優先のレイアウト（320px〜デスクトップまで対応、ダークモード対応）
- Lighthouse：パフォーマンス / アクセシビリティ / ベストプラクティス / SEO すべて100点
- CSP などのセキュリティヘッダー設定済み、外部ライブラリなし
- 接続情報はその端末のブラウザにだけ保存されます

## GAS単体でスマホから使いたい場合（任意）

1. Apps Scriptエディタで **デプロイ → 新しいデプロイ**
2. 種類: **ウェブアプリ**
3. 実行ユーザー: **自分** / アクセスできるユーザー: **自分のみ**
   （Netlify版と併用する場合は上の手順どおり **全員** にしてください）
4. デプロイして表示されたURLをスマホのブックマークやホーム画面に追加

## 残高の考え方

```
相手ごとの残高 = (貸した − 返してもらった) − (借りた − 返した)
```

- プラス → 相手から**返してもらう**額
- マイナス → 相手に**返す**額

## シートの形式

「取引」シート（自動作成）:

| ID | 日付 | 相手 | 種別 | 金額 | メモ | 登録日時 |
|----|------|------|------|------|------|----------|

シートに直接行を追加してもアプリに反映されます（IDは空でなければ何でもOK）。
